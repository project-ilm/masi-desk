## 0.1.0

The gate judges the test suite by its exit code. It once read the summary line from the end of
the output, which misty's printed JSON could follow, so a passing suite could read as failing.
misty's output during a test is now kept in the result, not printed.

The first release: a local rehearsal of the desk, partial against `desk-requirements.md`.
It launches a journal, a conference or a book, appends events, folds them into a state with
several dimensions, and regenerates indexes. It does not mint, push or stamp on its own
behalf. Before release it was checked and corrected; `docs/CHECK.md` records each correction
and what remains open, including blind arrival, which is refused.
