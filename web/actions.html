Actions

The workflow accepts workflow_dispatch. After the repository is seeded, the URL is:

https://github.com/zistgah/masi/actions/workflows/desk.yml

Locally, the same dispatch uses the GitHub CLI:

gh workflow run desk.yml --ref main -f kind=journal -f title=Example

This page does not call gh. The script bin/dispatch.sh does.
