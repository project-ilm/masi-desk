Documentation

The static pages are GitHub Pages. The Python desk runs locally. JavaScript in masi.js folds events, checks G3, and hashes a salted identifier in the browser. It does not mint.

Start the server

python3 -m masi.server

The desk page then calls /api/health, /api/launch, and /api/venues.

What is not a mint

misty publish --dry-run returns doi: null. A missing OpenTimestamps proof is pending_external. A GitHub issue is not opened by these pages.
